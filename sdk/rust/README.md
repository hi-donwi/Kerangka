# Kerangka Rust SDK

Specification Version: 0.1
Status: Scaffolded / Tier 2
License: Apache-2.0

## Overview

The Kerangka Rust SDK provides idiomatic Rust bindings for consuming and executing Kerangka applications. It supports driving declarative models using the `kerangka serve --stdio` JSON-RPC sidecar protocol, deserializing strongly-typed entity models generated by `kerangka codegen --target rust`, and dispatching actions with actor roles.

## Features

- **Sidecar Client:** Drive any `.kerangka.json` model synchronously or asynchronously over JSON-RPC 2.0 without embedding JavaScript or V8.
- **Typed Entity Models:** Pair with `kerangka codegen --target rust` to get serde-compatible Rust structs and enums.
- **Fail-Closed Permissions:** Dispatch actions passing `Actor` roles and verify refusal codes (`PERMISSION_DENIED`, etc.).

## Usage Example

### 1. Generate Models

```bash
kerangka codegen examples/invoicing.kerangka.json --target rust -o src/models.rs
```

### 2. Drive the Model from Rust

```rust
use kerangka::{Actor, SidecarClient};
use serde_json::json;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Spawn the Kerangka sidecar process
    let mut client = SidecarClient::spawn("examples/invoicing.kerangka.json")?;

    let draft = json!({
        "number": "INV-2026-001",
        "customer": "cust-01",
        "status": "draft",
        "issuedOn": "2026-10-11",
        "dueDate": "2026-11-11",
        "lines": [
            {
                "description": "Enterprise consulting",
                "qty": 10,
                "unitPrice": 150.0
            }
        ]
    });

    let actor = Actor {
        id: "user-1".to_string(),
        roles: vec!["billing".to_string()],
        tenant: None,
    };

    // Execute the action
    let result = client.run("Invoice.send", draft, Some(&actor))?;

    if result.ok {
        println!("Invoice sent successfully!");
        if let Some(record) = result.record {
            println!("Updated record: {}", record);
        }
    } else {
        eprintln!("Action refused: {:?}", result.message);
    }

    Ok(())
}
```
