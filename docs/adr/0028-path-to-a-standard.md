# ADR-0028: The Path to an Open Standard

- **Date:** 2026-09-27
- **Status:** Accepted
- **Deciders:** The Kerangka Authors
- **Project:** kerangka

## Context

A software description format controlled indefinitely by a single individual or company will never be trusted as a core industry standard.

## Decision

We establish a clear 4-stage governance progression: Open Specification (Phase 0) -> Multiple Certified Implementations (v1.0) -> Shared Steering Committee (Horizon 2) -> Neutral Foundation Application (Horizon 3, e.g. Linux Foundation or OpenJS).

## Consequences

### Positive
- Builds long-term enterprise trust; ensures Kerangka outlives any single company or maintainer.

### Negative
- Requires giving up unilateral control as the community grows.

### Neutral
- Brand and compatibility are protected by conformance certification.

## Alternatives Considered

| Option | Why rejected |
|---|---|
| Remaining a single-vendor proprietary format | Caps adoption and prevents true global standard status. |
